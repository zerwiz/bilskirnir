# 2026-11-22 — choosing a character fills its name

The Allfather: *"we should auto-fill their names in the name box when chosen, so the user can erase it and change it if he wants."*

In *Seat a new agent*, choosing a figure's character puts its name in the name box (the anvil → *Sindri*, the scales → *Forseti*). A name the person typed is never overwritten; a name the picker filled is replaced when another character is chosen, and can be erased or edited freely. The Ymir mark fills nothing.

Typecheck passes.
